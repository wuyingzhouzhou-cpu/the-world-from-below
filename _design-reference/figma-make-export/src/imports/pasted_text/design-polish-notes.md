----------------------------------------
1. REMOVE EDITOR-ONLY CONTROLS FROM PUBLIC UI
----------------------------------------

Remove all visible frontend controls such as:

ARTICLE MODE
PAPER / CINEMATIC

and

COVER MODE
A PHOTO / B TYPOGRAPHIC / C SPLIT

These will later be CMS editor settings.

Readers should only see the selected presentation.

Create the variants as separate design examples, not frontend tabs.

----------------------------------------
2. HOMEPAGE COVER
----------------------------------------

Keep three editorial homepage cover variants:

PHOTO
TYPOGRAPHIC
SPLIT

but show each as a separate design state.

PHOTO COVER must include the actual lead story identity.

Example:

WHEN THE FACTORY CLOSED

Work / Northeast China / Industrial Decline

Do not show only an unexplained photograph.

The opening editorial question remains:

“How do ordinary people live in a world they didn’t design?”

Reduce the overly literary/fashion-magazine quality of this statement.

Do NOT set the entire question in dramatic italic.

Prefer strong Roman serif typography.

Italic may be used selectively for emphasis only.

----------------------------------------
3. REDUCE ITALIC OVERUSE
----------------------------------------

The current design uses editorial italic too frequently.

Keep italic mainly for:

- pull quotes
- short editorial asides
- selective emphasis

Use Roman serif or readable sans-serif for normal descriptions, deks and explanatory copy.

The publication should feel documentary and thoughtful, not precious or fashion-oriented.

----------------------------------------
4. HOMEPAGE LIBRARY
----------------------------------------

The Library INDEX may remain orderly and list-like.

But redesign the HOMEPAGE Library section so it does not look like three equal cards.

Use asymmetric editorial composition.

Feature:

A Tree Grows in Brooklyn
Still Life
Factory Girls

Vary:
image / cover scale
text position
whitespace
orientation

Do not make it ecommerce.

----------------------------------------
5. LIBRARY STATUS

Do not expose backend workflow metadata unless it has genuine reader value.
